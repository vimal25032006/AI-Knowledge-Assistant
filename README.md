## 📖 About

AI Knowledge Assistant is an AI-powered application that enables users to upload PDF documents and ask questions based on their content.

The application extracts text from uploaded PDFs and uses **Groq Llama 3.1** to generate intelligent, context-aware answers.

---

## ✨ Features

- 📄 Upload PDF documents
- 🤖 Ask questions from uploaded PDFs
- ⚡ Powered by Groq Llama 3.1
- 📚 Endee.io Integration
- 💬 Interactive Chat Interface
- 🌐 Streamlit Cloud Deployment
- 🚀 Fast and User-Friendly Interface

---

## 🛠️ Tech Stack

- Python
- Streamlit

- Endee.io

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/vimal25032006/AI-KNOWLEDGE-ASSISTANT.git
```

Go to the project folder:

```bash
cd AI-KNOWLEDGE-ASSISTANT
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```
